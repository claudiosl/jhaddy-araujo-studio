## 🛠️ Como Personalizar via [`config.js`](file:///c:/meu-projeto/clientes/jhaddy-araujo-studio/config.js)

Todo o site foi programado para puxar as informações essenciais de um único arquivo: **[`config.js`](file:///c:/meu-projeto/clientes/jhaddy-araujo-studio/config.js)**.

Para alterar dados, abra o arquivo `config.js` e atualize:
- `clinicName`: Nome do estúdio.
- `contact.whatsapp`: Número com DDD (ex: "5571987870244").
- `contact.address`: Endereço completo.
- `tracking`: Inserir IDs do GA4 (`G-XXXXXXXXXX`) ou Meta Pixel (`1234567890123456`).
